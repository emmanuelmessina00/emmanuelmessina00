### 🔬 Highlighted Engineering Projects

- **[xai-project5](https://github.com/emmanuelmessina00/xai-project5): Interpretability in Medical VLMs via SAE**  
  PyTorch pipeline for unsupervised extraction of clinical concepts from BioMedCLIP features using Sparse Autoencoders (SAE), evaluating semantic separability of latent representations.

- **[edge-biomechanics-classifier](https://github.com/emmanuelmessina00/edge-biomechanics-classifier): Edge AI on ESP32 in Rust**  
  Biomechanics classification pipeline trained in Python (PCA, LDA, Gaussian classifiers, Logistic Regression) paired with an on-device inference engine in bare-metal Rust (`#![no_std]`) for ESP32.

- **[fingerprint-spoofing-detection](https://github.com/emmanuelmessina00/fingerprint-spoofing-detection): Pattern Recognition & Verification**  
  Statistical liveness detection benchmark comparing SVM, GMM, Logistic Regression, and MVG with Bayesian decision evaluation (MinDCF, Bayes Error Plots).

- **[totodile-esp32-rust](https://github.com/emmanuelmessina00/totodile-esp32-rust): Embedded Systems & Hardware Control**  
  Bare-metal Rust firmware on ESP32 featuring hardware register control, I2C/SPI communication, and real-time OLED rendering.
